Physical AI Humanoid Mobile Manipulator Startup

AIRoA, Physical AI 데이터 수집용 국산 범용로봇 7종 공개

2026.09.17 06:45
High

① AIRoA가 Physical AI Summit에서 국산 범용로봇 개발 Competition 참가 7개 팀의 Prototype을 공개했음. THK, ugo, Nachi-Fujikoshi, Keigan, Enactic, Emplifi, HatsuMuv가 참여하며 핵심 Target은 Physical AI용 양팔 Mobile Manipulator임.

② NEDO의 Robot Foundation Model용 Data Platform 사업의 일부로 추진되며, 2026년 Prototype → 2027년 Improved Model → Mass-production Model로 발전할 예정임. 평가기준을 충족한 Robot은 실제 Foundation Model 학습 Data Collection에 활용됨.

③ 배경에는 중국 Humanoid Hardware의 빠른 성장과 중국산 Data Collection Robot 의존에 대한 공급망 우려가 있음. 일본은 Robot Hardware→Data→VLA/VTLA→Foundation Model을 국내 생태계로 연결하는 전략을 구체화하고 있음.

주요 참가기업

ugo

국산 Semi-humanoid 'ugo Nova'를 공개했음. 양팔 최대 가반 10kg, Mecanum 기반 전방향 이동, NVIDIA Jetson Thor를 탑재하며 VLA에 촉각을 추가한 VTLA Model 개발까지 추진하고 있음.

Keigan

24축 자체 Actuator, 자체 Motor Driver와 Control SW, 일본산 Reducer를 적용하고 있음. 설계정보와 SDK를 Open-source화해 수리·보수·개조가 쉬운 Robot Platform을 지향함.

Nachi-Fujikoshi

기존 Industrial Robot 기술을 활용한 Dual-arm Robot으로 VLA 등 AI Model 적용을 전제로 개발 중임.

THK

Linear Guide·Ball Screw 등 기존 정밀기계요소 기술을 활용해 고강성·고정밀·고내구 범용 Robot Hardware로 확장하고 있음.

Enactic

완전 Open-source Dual-arm Robot Platform 'OpenArm'을 기반으로 참가했으며 Arm당 5.5kg 가반과 복수 Gripper를 적용하고 있음.

POSCO 시사점

일본의 Physical AI 경쟁축이 개별 Robot Application에서 Foundation Model용 Data Infrastructure로 이동하고 있음.

향후 Robot 기업 평가 시 Payload·DOF·가격만 볼 것이 아니라 Hardware + Data Collection + VLA/VTLA Compatibility + Actuator 내재화 + Open SDK + Manufacturing Data 확보능력을 함께 평가해야 함.

Startup 관점에서는 ugo와 Keigan을 우선 Tracking할 가치가 높으며, AIRoA Data Collection Platform 최종 채택 여부가 중요한 사업화 Milestone이 될 수 있음.
